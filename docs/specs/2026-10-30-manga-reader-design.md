# Manga Reader — спецификация (дизайн v1)

Дата: 2026-10-30
Статус: на согласовании
Название «Manga Reader» временное.

## 1. Цель

Десктопная программа для Windows для чтения raw-манги и комиксов (CBZ и другие форматы) и работы с ними. Это не только читалка, а инструмент:

- понятная навигация по сериям, томам и главам;
- сохранение понравившейся страницы или выделенного мышью фрагмента («ножницы») в исходном качестве или в другом формате с пониженным качеством;
- пакетный экспорт глав и томов;
- постраничное чтение текстовых книг (EPUB, FB2, MOBI).

Ориентир по удобству — Xylasoft Comic Seer. Копией Comic Seer программа не будет.

### Для кого и как

- Основной пользователь — автор проекта.
- ОС — Windows 10/11 x64. Код кроссплатформенный (тесты идут и на Linux), но сборка и поддержка рассчитаны только на Windows.
- Программа **портативная**: скачать zip, распаковать в любую папку (можно на флешку), запустить `MangaReader.exe`. Ни установщика, ни записей в реестр.
- Файлы лежат на компьютере. Онлайн-каталоги и скачивание из интернета не входят в объём.

### Критерии успеха

1. Можно открыть папку или файл любого поддерживаемого формата, быстро перейти к нужному тому, главе или странице и листать без заметных задержек.
2. Фрагмент выделяется мышью (в том числе через разворот) и за пару кликов сохраняется в нужный формат или копируется в буфер обмена. Пиксели берутся из оригинала, а не с экрана.
3. «Как в оригинале» для целой страницы даёт байт-в-байт копию файла из архива.
4. Ручная разметка глав и прогресс чтения сохраняются между запусками и переживают переименование или перенос файла.
5. Программа запускается из любой папки и хранит все свои данные рядом с exe.

## 2. Объём

### Входит в v1 (этапы 1–3)

- Открытие: CBZ/ZIP, CBR/RAR, CB7/7z, папки с картинками, PDF, EPUB, FB2, MOBI, XPS, TXT.
- Картинки внутри: JPG, PNG, WEBP, AVIF, JPEG XL, BMP, GIF (первый кадр), TIFF.
- Библиотека с обложками, прогрессом, «Продолжить чтение», поиском и фильтрами.
- Читалка: одиночная страница, разворот, вертикальная лента; направление справа налево и слева направо; режимы масштаба.
- Дерево «том → глава», миниатюры, ручная разметка глав.
- «Ножницы», буфер обмена, сохранение страницы или фрагмента во все форматы.
- Пакетный экспорт (страницы, главы, тома) в картинки, PDF и CBZ.
- Портативная сборка и автоматический выпуск через GitHub Releases.

### Не входит в v1 (следующие этапы)

- Полноценная читалка книг: выбор шрифтов, темы оформления, выделение и копирование текста, заметки.
- Английский интерфейс (строки сразу оформляются через механизм перевода Qt, чтобы потом его было легко добавить).
- Онлайн-источники, синхронизация, OCR и перевод.
- Ассоциации файлов в Windows (противоречат портативности); открыть файл можно через «Открыть с помощью…» или перетаскиванием.
- Переназначение горячих клавиш.

## 3. Термины

| Термин | Что это |
|---|---|
| **Источник страниц** | То, что открывается как упорядоченный набор страниц: архив, документ или папка, непосредственно содержащая картинки. |
| **Серия** | Папка, объединяющая тома и главы одного произведения, или одиночный файл. |
| **Том** | Источник страниц или папка источников, классифицированные как том. |
| **Глава** | Источник страниц, папка внутри архива или участок тома, начинающийся с ручной отметки. |
| **Отпечаток** | Хеш от размера файла и списка имён и размеров страниц внутри. По нему файл узнаётся после переименования. |

## 4. Форматы и их открытие

### 4.1 Определение формата

Формат определяется по сигнатуре файла, а не по расширению: CBZ, который на самом деле RAR, встречается часто.

| Сигнатура | Формат | Чем открывается |
|---|---|---|
| `PK\x03\x04` + `mimetype` = `application/epub+zip` | EPUB | MuPDF |
| `PK\x03\x04` | ZIP/CBZ | `zipfile` (Python) |
| `Rar!\x1a\x07` | RAR/CBR (RAR4 и RAR5) | 7-Zip |
| `7z\xbc\xaf\x27\x1c` | 7z/CB7 | 7-Zip |
| `%PDF` | PDF | MuPDF |
| по расширению | FB2, MOBI, XPS, TXT | MuPDF |
| папка | папка с картинками | файловая система |

### 4.2 Правила для архивов и папок

- Страницы — все файлы картинок, рекурсивно, включая вложенные папки. Остальное игнорируется: `.txt`, `.xml`, `.nfo`, `Thumbs.db`, `__MACOSX/`, `._*`, `desktop.ini`.
- Порядок **естественный**: `2.jpg` раньше `10.jpg`, `ch2/` раньше `ch10/`. Сравнение без учёта регистра, числа внутри имени сравниваются как числа.
- **Кодировка имён в ZIP.** Если у имени нет флага UTF-8, программа выбирает кодировку для всего архива так: UTF-8, если все имена в ней читаются без ошибок; иначе CP932 (Shift-JIS, японские архивы), если все имена читаются и среди них есть японские символы (кана или иероглифы); иначе CP866 (русские архивы из Windows). Без этого японские raw-архивы показывают «кракозябры» вместо названий глав.
- **RAR и 7z** читаются через консольный 7-Zip (`7zz`), который берётся из Python-пакета `py7zz` и кладётся в папку программы. Сначала читается оглавление архива, затем архив один раз распаковывается целиком во временную папку в фоновом процессе. Страницы становятся доступны по мере распаковки. Для «сплошных» (solid) архивов это единственный быстрый способ. Каждый запуск программы получает свою папку `data/cache/extract/run-…/` с файлом-замком, поэтому второй запущенный экземпляр не трогает файлы первого. Временные папки удаляются при закрытии источника, при выходе из программы и при следующем запуске (только папки завершившихся запусков); лимит кэша распаковки 4 ГБ на запуск, старые удаляются первыми. На Windows 7-Zip заменяет в именах символы `: * ? " < > |`; программа находит такие файлы по «нормализованному» имени.
- **Архивы с паролем**: программа спрашивает пароль и не сохраняет его. Зашифрованные ZIP тоже открываются через 7-Zip.

### 4.3 Документы (MuPDF)

- **PDF, XPS** показываются как есть. Если страница PDF состоит из одной картинки на весь лист (так устроено большинство PDF с мангой), то «оригиналом» считается эта встроенная картинка: её байты используются для «Как в оригинале» и для вырезания фрагментов. Иначе страница рендерится, по умолчанию с разрешением 300 DPI.
- **EPUB, FB2, MOBI, TXT** — «текучие» документы. MuPDF разбивает их на страницы под размер окна с выбранным размером шрифта (ползунок 8–24 pt). При смене размера окна или шрифта страницы пересчитываются, а позиция чтения хранится как «номер главы + место внутри главы» (а не номер страницы), поэтому место не теряется ни при смене шрифта, ни после повторного открытия. Закладки MuPDF для этого не годятся: они действуют только пока файл открыт.
- EPUB с мангой (картинка на страницу) показывается как обычные страницы, но ведёт себя как документ.

## 5. Структура: серии, тома, главы

### 5.1 Правила классификации

Внутри папки серии:

1. **Подпапка, содержащая источники** (архивы, документы, папки с картинками) — это **том-папка**, а её источники — **главы** (раскладка «CBZ = глава, тома — папки на диске»).
2. **Источник, внутри которого две или больше папок с картинками** — это **том**, а внутренние папки — **главы** (раскладка «CBZ = том, внутри папки по главам»). Одна папка-обёртка внутри архива не считается главой и пропускается.
3. **Остальные источники** классифицируются по имени (без учёта регистра):
   - глава: `ch`, `chap`, `chapter`, `c<число>`, `глава`, `гл.`, `第<число>話`, `話`, `ep`, `episode`;
   - том: `vol`, `volume`, `v<число>`, `том`, `т.<число>`, `第<число>巻`, `巻`, `tome`.
   - Если имя не подсказывает, решает число страниц: 100 и больше — том, меньше — глава.
4. **Том без глав внутри** (раскладка «CBZ = том, страницы подряд») получает главы из ручной разметки (раздел 5.2).
5. Главы, не входящие ни в один том, показываются в дереве на верхнем уровне серии, после всех томов.
6. Из имени извлекается номер (`Том 3`, `Глава 21.5`), по нему идёт сортировка, а при равенстве — естественная сортировка по имени.
7. Любое решение можно исправить: правый клик → «Это том» или «Это глава». Исправление сохраняется.
8. Файлы `.txt` в папке серии источниками не считаются (обычно это readme); TXT открывается только явно через «Открыть файл». Источники без единой страницы в дерево не попадают.

**Где серия.** В библиотеке (этап 2) серия — это папка верхнего уровня внутри папки библиотеки или файл прямо в её корне. Без библиотеки (этап 1, «Открыть файл»): серия — ближайшая папка-родитель открытого файла, не являющаяся том-папкой. Если открыта папка с картинками, то она сама источник, а серия — её родитель по тем же правилам.

### 5.2 Ручная разметка глав

- Правый клик по миниатюре → «Здесь начинается глава…». Программа предлагает следующий номер, его можно изменить и добавить название.
- Отметку можно переименовать или удалить. Страницы до первой отметки показываются в дереве как «Начало».
- Разметка хранится в базе и привязана к источнику через путь и отпечаток.

## 6. Интерфейс

Язык интерфейса русский. Тёмная тема по умолчанию, светлая по выбору. Два экрана: Библиотека и Читалка.

### 6.1 Библиотека (этап 2)

- В настройках задаётся одна или несколько папок библиотеки.
- Сверху лента «Продолжить чтение»: до 10 источников с незавершённым прогрессом, свежие первыми.
- Ниже сетка серий с обложками (обложка — первая страница первого источника) и полоской прогресса.
- Поиск по названию: подстрока, без учёта регистра, `ё` = `е`.
- Фильтры: «Все», «Читаю», «Не начато», «Прочитано».
- Клик по серии открывает дерево томов и глав с обложками и прогрессом. Правый клик: «Отметить прочитанным», «Отметить непрочитанным», «Это том» / «Это глава», «Экспортировать…» (этап 3).
- Сканирование идёт в фоне при запуске и по кнопке «Обновить». Файлы, которые не удалось открыть, попадают в список «Не удалось открыть» с причиной.
- Если папка библиотеки не найдена (например, у флешки сменилась буква диска), программа предлагает указать новое расположение и переносит на него все пути.

### 6.2 Читалка

```
┌───────────────────────────────────────────────────────────┐
│ ← Библиотека │ Серия › Том 3 › Глава 21 │ 45/212 │ ✂ 💾 ⚙ │
├──────────────┬────────────────────────────────────────────┤
│ ▸ Том 1      │                                            │
│ ▾ Том 3      │         страница или разворот              │
│    Глава 20  │                                            │
│  ► Глава 21  │                                            │
│ ──────────── │                                            │
│ [миниатюры]  │                                            │
├──────────────┴────────────────────────────────────────────┤
│ ◂━━━━━━━━━━━━━━━━━━●──────────────────── ползунок страниц  │
└───────────────────────────────────────────────────────────┘
```

- **Левая панель** (скрывается клавишей Tab): дерево серии «том → глава» и миниатюры страниц текущего источника. Текущая глава подсвечена.
- **Режимы чтения:**
  - *Одна страница.*
  - *Разворот.* Первая страница (обложка) идёт одна. Широкая страница (ширина больше высоты) идёт одна. Остальные страницы идут парами. Клавиша O сдвигает пары на одну страницу, если развороты «съехали»; сдвиг запоминается для источника. При чтении справа налево первая страница пары справа.
  - *Вертикальная лента* для вебтунов: страницы встык по вертикали, непрерывная прокрутка.
- **Направление**: справа налево (по умолчанию для архивов и папок) или слева направо (по умолчанию для документов). Направление и режим запоминаются для каждой серии.
- **Масштаб**: по ширине, по высоте, целиком в окне, 100% (пиксель в пиксель). Ctrl+колесо — свободный масштаб, перетаскивание мышью — сдвиг.
- **Качество показа**: уменьшенная для экрана версия страницы строится в фоне фильтром Lanczos под точный размер окна с учётом масштабирования Windows. Это убирает муар на скринтонах. Пока она готовится, показывается быстрое приближение.
- **Колесо мыши**: если страница целиком в окне — листает; если страница больше окна — прокручивает, а у края листает дальше. В вертикальной ленте колесо всегда прокручивает.
- **Клик** по левой или правой трети страницы листает назад или вперёд с учётом направления.
- **Переход между источниками**: после последней страницы открывается первая страница следующего источника в дереве, а назад — последняя страница предыдущего. Короткая всплывающая подпись показывает, куда вы перешли («Том 4»).
- **Текстовые книги**: в верхней панели появляется ползунок размера шрифта.
- **Открытие** (этап 1): Ctrl+O — файл, Ctrl+Shift+O — папка, перетаскивание в окно, список недавних, путь в командной строке.

### 6.3 Горячие клавиши

| ← / → | Листать. При чтении справа налево ← — вперёд. |
| Пробел / Shift+Пробел | Вперёд / назад (сначала прокрутка, если страница больше окна) |
| PgDn / PgUp | Следующая / предыдущая страница |
| Home / End | Первая / последняя страница источника |
| Ctrl+PgDn / Ctrl+PgUp | Следующая / предыдущая глава |
| 1 / 2 / 3 | Одна страница / разворот / вертикальная лента |
| W / H / F / Z | По ширине / по высоте / в окне / 100% |
| O | Сдвиг разворота |
| D | Сменить направление чтения |
| S | Ножницы (режим выделения) |
| Ctrl+C | Копировать выделение (без выделения — всю текущую страницу, в развороте — обе страницы склеенными) |
| Ctrl+S | Сохранить страницу или выделение (окно сохранения) |
| Ctrl+Shift+S | Быстрое сохранение с последними настройками |
| Enter / Esc | В режиме выделения: сохранить / отменить |

| Backspace | В библиотеку (этап 2) |
| Ctrl+O / Ctrl+Shift+O | Открыть файл / папку |

## 7. Выделение («ножницы»)

- Клавиша S или кнопка ✂ включают режим выделения: курсор-крестик, вы тянете прямоугольник. Рамку можно двигать и менять за 8 маркеров. Рядом подпись с размером в пикселях оригинала, например `1840 × 2610`.
- Координаты рамки переводятся из экранных в координаты оригинальных изображений. Масштаб просмотра на результат не влияет.
- Выделение может охватывать несколько видимых страниц (разворот или соседние страницы в ленте). Тогда части склеиваются в той раскладке, что на экране: по горизонтали для разворота, по вертикали для ленты. Если страницы разного размера, меньшая масштабируется (Lanczos) к высоте (для разворота) или ширине (для ленты) большей, чтобы не терять детали большей страницы. Зазора между частями нет.
- Если выделение лежит на одной странице, вырезается только из неё, без масштабирования.
- Ctrl+C — в буфер обмена, Enter — окно сохранения, Esc — отмена.

## 8. Экспорт

### 8.1 Что можно сохранить

| Что | Как вызвать | Этап |
|---|---|---|
| Фрагмент | Ножницы → Enter / Ctrl+S | 1 |
| Текущая страница или разворот | 💾 / Ctrl+S без выделения | 1 |
| Несколько страниц | Выбор миниатюр с Ctrl/Shift → «Экспортировать…» | 3 |
| Глава, том, несколько глав или томов | Правый клик в дереве → «Экспортировать…» | 3 |

Для разворота окно сохранения предлагает «две отдельные страницы» или «склеить в одну картинку» (правила склейки из раздела 7).

### 8.2 Окно сохранения

- **Формат**: «Как в оригинале», PNG, JPEG, WEBP, AVIF, TIFF, BMP, PDF. Для пакета ещё CBZ.
- **Качество** (JPEG, WEBP, AVIF): ползунок 1–100 и готовые варианты.

  | Вариант | JPEG | WEBP | AVIF |
  |---|---|---|---|
  | Максимум | 100 | 100 | 95 |
  | Высокое | 92 | 90 | 80 |
  | Среднее | 85 | 80 | 65 |
  | Компактное | 75 | 70 | 50 |

- **Размер**: оригинал; процент от оригинала; длинная сторона в пикселях. Уменьшение — Lanczos, увеличение не делается.
- **Примерный размер файла** для одиночной картинки: кодирование в памяти в фоне, обновляется через полсекунды после изменения настроек.
- **Пакет**: одним файлом (PDF, CBZ) или папкой с картинками.
- **Шаблон имени**: подстановки `{серия}`, `{том}`, `{глава}`, `{страница}`, `{файл}` (исходное имя). По умолчанию `{серия} – Том {том} – Гл {глава} – стр {страница}`. Номера дополняются нулями (`03`, `045`). Если части нет (например, нет тома), она убирается вместе с соседним разделителем. Запрещённые в Windows символы заменяются на `_`. При совпадении имён добавляется ` (2)`, ` (3)`.
- Последние папка, формат и настройки запоминаются. Ctrl+Shift+S сохраняет с ними без окна и показывает подсказку «Сохранено: …» с кнопкой «Открыть папку».

### 8.3 Правила качества

- **«Как в оригинале», целая страница**: байты файла копируются без изменений, расширение сохраняется.
- **«Как в оригинале», фрагмент или склейка**: формат как у источника.
  - PNG, BMP, TIFF — без потерь.
  - WEBP — в режиме без потерь.
  - JPEG — с таблицами квантования и субдискретизацией оригинала. Потери минимальны, но не нулевые, и об этом есть подсказка: «Для нулевых потерь выберите PNG».
  - AVIF и JPEG XL — максимальное качество (JPEG XL сохраняется только так; в общем списке форматов его нет).
  - GIF — в PNG.
  - У склейки из страниц разных форматов результат PNG.
- **Цвет**: ICC-профиль источника сохраняется. Чёрно-белые страницы остаются в оттенках серого, без перевода в RGB (меньше файл). Прозрачность при сохранении в JPEG заливается белым.
- **JPEG**: при качестве 90 и выше субдискретизация 4:4:4, чтобы цветной текст оставался чётким; включена оптимизация таблиц Хаффмана.
- **PDF**: одна картинка на страницу. Размер листа считается из пикселей при 300 DPI. «Как в оригинале» встраивает JPEG без перекодирования, а PNG — без потерь.
- **CBZ**: без сжатия (картинки уже сжаты), страницы переименовываются в `0001.ext`, `0002.ext`… «Как в оригинале» даёт байт-в-байт переупаковку, в том числе CBR → CBZ.

### 8.4 Фоновые задания (этап 3)

- Пакетный экспорт идёт в отдельном потоке. Справа внизу видна панель заданий с прогрессом и кнопкой «Отмена». Читать в это время можно.
- Ошибка в одном файле не останавливает остальные. В конце показывается итог: «Сохранено 210 из 212» и список неудачных страниц с причинами.
- При отмене уже сохранённые файлы остаются, а недописанный файл (PDF или CBZ) удаляется.

## 9. Устройство программы

Язык Python 3.13, интерфейс PySide6 (Qt 6). Логика (источники, классификация, экспорт) не зависит от Qt и тестируется отдельно от интерфейса.

### 9.1 Структура кода

```
src/mangareader/
  __main__.py          запуск, разбор аргументов (--self-test, путь к файлу)
  paths.py             где лежит data/ (портативность)
  sources/             «открыватели»
    base.py            PageSource, PageRef
    detect.py          определение формата по сигнатуре
    natsort.py         естественная сортировка
    folder.py  zip.py  sevenzip.py (RAR и 7z через 7zz)  document.py (MuPDF)
  library/
    classify.py        правила раздела 5.1
    scanner.py         обход папок
    store.py           база SQLite
    fingerprint.py     отпечатки
  render/
    decode.py          расшифровка картинок (Pillow) → QImage
    cache.py           кэш расшифрованных страниц с лимитом памяти
    thumbs.py          миниатюры и их дисковый кэш
  export/
    crop.py  stitch.py  encoders.py  pdf.py  cbz.py  naming.py  jobs.py
  ui/
    main_window.py  reader/  library/  dialogs/  theme.py
tests/
packaging/             настройки PyInstaller, образец для --self-test
.github/workflows/     ci.yml, release.yml
```

### 9.2 Ключевые интерфейсы

- `open_source(path) -> PageSource` выбирает «открыватель» по сигнатуре.
- `PageSource`:
  - `pages: list[PageRef]` — для каждой страницы индекс, внутренний путь, папка внутри архива, расширение, размер в байтах;
  - `read_original(i) -> bytes | None` — исходные байты страницы (`None`, если у страницы документа нет единственной встроенной картинки);
  - `load_image(i) -> PIL.Image` — полноразмерное изображение (для документов — рендер);
  - `is_reflowable`, `relayout(width, height, font_size)` — только для текучих документов;
  - `close()`.
- `classify(series_dir, overrides) -> SeriesTree` — дерево «том → глава» с номерами и источниками.
- `Store` — чтение и запись прогресса, отметок глав, исправлений типа, настроек серии; поиск по отпечатку.
- `ExportRequest` → `run_export(request, progress, cancel) -> ExportReport`. Запрос описывает выбранные страницы, рамку в координатах оригинала, раскладку (отдельно или склейка), формат, качество, размер, путь или шаблон. Функция не зависит от Qt.

### 9.3 Показ страниц и производительность

- Картинки расшифровываются в пуле потоков (Pillow). Для миниатюр JPEG используется быстрый режим `draft`.
- Предзагрузка: 2 страницы (или 2 разворота) вперёд и 1 назад.
- Кэш расшифрованных страниц ограничен по памяти: по умолчанию 1 ГБ, меняется в настройках. Вытесняются давно не использованные.
- Миниатюры высотой 240 px хранятся в `data/cache/thumbs/` в WEBP, ключ — отпечаток источника и номер страницы.
- Цель: листание вперёд по предзагруженным страницам без видимой задержки (меньше 100 мс), первая страница нового источника открывается меньше чем за 1 с для ZIP и папок.

## 10. Хранение данных (портативность)

- Папка данных — `data/` рядом с `MangaReader.exe`. При запуске из исходников — `data/` в корне проекта (не попадает в git). Для тестов путь задаётся переменной `MANGAREADER_DATA`.
- Если рядом с exe нельзя писать (например, Program Files), программа предупреждает и использует `%LOCALAPPDATA%\MangaReader\`.
- Содержимое `data/`:
  - `library.db` — SQLite;
  - `settings.json` — настройки (тема, кэш, последние параметры экспорта, недавние файлы);
  - `cache/thumbs/`, `cache/extract/` — кэши, их можно удалять;
  - `logs/manga-reader.log` — журнал, 5 файлов по 1 МБ по кругу.
- Таблицы базы (основные):
  - `sources` — путь (абсолютный на этапе 1, относительно папки библиотеки на этапе 2), размер и время изменения файла, отпечаток, число страниц, исправление типа (том или глава), сдвиг разворота, когда последний раз видели. Размер и время изменения позволяют не перечитывать оглавление неизменившихся архивов;
  - `progress` — источник, позиция (номер страницы или закладка MuPDF), «прочитано», время;
  - `chapter_marks` — источник, страница, номер, название;
  - `series_prefs` — серия, направление, режим;
  - этап 2: `roots` (папки библиотеки), `series`.
- Узнавание файлов: если при открытии или сканировании записи по пути нет, ищется запись с таким же отпечатком, путь которой больше не существует. Найденная запись переносится на новый путь вместе с прогрессом и разметкой.
- Обновление схемы базы — нумерованные миграции при запуске; перед миграцией делается копия `library.db.bak`.

## 11. Ошибки

- Повреждённый архив или нечитаемая картинка не роняют программу. На месте страницы рисуется заглушка с причиной («Не удалось прочитать страницу: файл повреждён»).
- Ошибки сканирования копятся в списке «Не удалось открыть».
- Непредвиденная ошибка показывает окно с кратким текстом и кнопкой «Открыть журнал». Полный стек пишется в журнал.
- Нехватка места или нет прав при экспорте — понятное сообщение, частичный файл удаляется.
- Если 7-Zip не найден рядом с exe (повреждённая сборка), RAR и 7z не открываются, остальное работает, а сообщение объясняет причину.

## 12. Тестирование

- `pytest` для логики и `pytest-qt` для интерфейса, интерфейс без экрана (`QT_QPA_PLATFORM=offscreen`).
- **Тестовые данные** генерируются в тестах: пронумерованные страницы с известными цветами пикселей во всех форматах картинок; ZIP/CBZ (в том числе с именами в CP932 и CP866, с папками глав, с папкой-обёрткой); 7z (создаётся тем же `7zz`); PDF (MuPDF), EPUB и FB2 (собираются вручную). RAR создать без WinRAR нельзя, поэтому в репозитории лежат маленькие готовые образцы RAR4 и RAR5. MOBI автотестом не покрывается (его нельзя сгенерировать без внешних программ) и проверяется вручную.
- **Что проверяется**:
  - определение форматов по сигнатуре, в том числе CBZ, который на самом деле RAR;
  - естественная сортировка и кодировки имён;
  - все правила классификации раздела 5.1 и исправления;
  - ручная разметка и её перенос после переименования;
  - вырезание: фрагмент совпадает с оригиналом попиксельно; склейка разворота и ленты; перевод экранных координат в координаты оригинала при разных масштабах;
  - экспорт: байт-в-байт для «Как в оригинале», каждый формат открывается обратно, качество и размер применяются, шаблоны имён, переупаковка CBR → CBZ, PDF со встроенным JPEG без перекодирования;
  - сценарии интерфейса: открыть → листать → режимы → выделить → сохранить.

## 13. Сборка и выпуск

- GitHub Actions:
  - `ci.yml` — на каждый push: тесты на `ubuntu-latest` и `windows-latest`;
  - `release.yml` — на тег `v*`: тесты, сборка PyInstaller в режиме папки (onedir, без консольного окна), в папку кладётся `7zz.exe`, затем проверка `MangaReader.exe --self-test`. Самопроверка открывает встроенный образец, рендерит страницу, вырезает фрагмент, экспортирует его во временную папку и завершается с кодом 0. После неё папка упаковывается в `MangaReader-<версия>-win64.zip` и публикуется в GitHub Releases.
- Версии: `0.1.0` — этап 1, `0.2.0` — этап 2, `0.3.0` — этап 3, исправления увеличивают последнюю цифру.
- Ожидаемый размер распакованной папки 200–300 МБ, запуск 1–3 с.
- У exe нет платной цифровой подписи, поэтому при первом запуске Windows SmartScreen может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае». В README это объяснено с картинкой.

## 14. Этапы

1. **Читалка и ножницы (0.1.0).** Все источники (раздел 4); классификация и дерево серии вокруг открытого файла (раздел 5); ручная разметка; все режимы чтения, масштаба и навигации (раздел 6.2–6.3, кроме библиотеки); миниатюры; запоминание позиции; ножницы, буфер обмена, сохранение страницы, разворота или фрагмента во все форматы (разделы 7, 8.1–8.3 для одиночных картинок); портативные данные; сборка и выпуск.
2. **Библиотека (0.2.0).** Раздел 6.1: папки библиотеки, сканирование, серии с обложками, «Продолжить чтение», поиск, фильтры, отметки прочитанного, перенос папки библиотеки.
3. **Пакетный экспорт (0.3.0).** Выбор нескольких страниц, экспорт глав и томов, PDF и CBZ из нескольких страниц, переупаковка, шаблоны имён, быстрое сохранение для пакета, фоновые задания (раздел 8.4).
4. **Дальше.** Полноценная читалка книг, английский интерфейс, другие пожелания.

Спецификация описывает программу целиком. План работ пишется отдельно для каждого этапа, начиная с первого.
