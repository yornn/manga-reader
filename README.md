# Manga Reader

Программа для Windows, чтобы читать raw-мангу, комиксы и книги и работать с ними: удобная навигация по томам и главам, «ножницы» для вырезания фрагментов из оригинала в полном разрешении и сохранение страниц в нужном формате.

Название «Manga Reader» временное.

## Как установить

Устанавливать ничего не нужно, программа портативная.

1. Откройте страницу [Releases](https://github.com/yornn/manga-reader/releases) и скачайте `MangaReader-<версия>-win64.zip`.
2. Распакуйте архив в любую папку, можно на флешку.
3. Запустите `MangaReader.exe`.

При первом запуске Windows может показать окно «Windows защитила ваш компьютер»: у программы нет платной цифровой подписи. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Изредка антивирусы ошибочно ругаются на программы, собранные таким способом (PyInstaller). Это не вирус.

## Где хранятся данные

Всё лежит в папке `data` рядом с `MangaReader.exe`: прогресс чтения, ручная разметка глав, настройки, кэш миниатюр и журнал ошибок. В реестр программа ничего не пишет. Переносите папку программы целиком, и все данные переедут вместе с ней.

Если рядом с программой нельзя сохранять файлы (например, её положили в `Program Files`), данные хранятся в `%LOCALAPPDATA%\MangaReader`, и программа об этом предупредит.

## Что открывает

- **Архивы и папки:** CBZ, ZIP, CBR, RAR, CB7, 7z, обычные папки с картинками. Тип архива определяется по содержимому, поэтому CBZ, который на самом деле RAR, тоже откроется. Японские (Shift-JIS) и русские (CP866) имена файлов внутри ZIP распознаются.
- **Картинки внутри:** JPG, PNG, WEBP, AVIF, JPEG XL, BMP, GIF, TIFF.
- **Документы и книги:** PDF, EPUB, FB2, MOBI, XPS, TXT. Текстовые книги разбиваются на страницы под размер окна, размер шрифта меняется ползунком.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| ← / → | Листать. При чтении справа налево ← — вперёд |
| Пробел / Shift+Пробел | Вперёд / назад (сначала прокрутка, если страница больше окна) |
| PgDn / PgUp | Следующая / предыдущая страница |
| Home / End | Первая / последняя страница |
| Ctrl+PgDn / Ctrl+PgUp | Следующая / предыдущая глава |
| 1 / 2 / 3 | Одна страница / разворот / вертикальная лента |
| W / H / F / Z | По ширине / по высоте / в окне / 100% |
| O | Сдвиг разворота на одну страницу |
| D | Сменить направление чтения |
| S | Ножницы (выделить фрагмент) |
| Ctrl+C | Копировать фрагмент или страницу в буфер обмена |
| Ctrl+S | Сохранить страницу или фрагмент |
| Ctrl+Shift+S | Быстрое сохранение с последними настройками |
| Enter / Esc | В режиме выделения: сохранить / отменить |
| Tab | Показать или скрыть левую панель |
| F11 | Полный экран |
| Ctrl+O / Ctrl+Shift+O | Открыть файл / папку |

Ещё можно листать кликом по левой или правой трети страницы и колесом мыши, а масштаб менять колесом с зажатым Ctrl.

## Для разработчика

Нужен Python 3.13.

```bash
python -m venv .venv
```

```bash
.venv/bin/pip install -e ".[dev]"
```

Тесты (на Linux для Qt нужны пакеты `libegl1 libxkbcommon0 libgl1 libfontconfig1 libdbus-1-3`):

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/pytest -q
```

Запуск из исходников:

```bash
.venv/bin/python -m mangareader
```

Сборка портативной папки и самопроверка:

```bash
.venv/bin/pyinstaller packaging/mangareader.spec --noconfirm
```

```bash
dist/MangaReader/MangaReader --self-test
```

Windows-сборку делает GitHub Actions (`.github/workflows/ci.yml`, job `build-windows`). Выпуск создаётся при отправке тега `v*` (`.github/workflows/release.yml`).

Спецификация: `docs/superpowers/specs/2026-10-30-manga-reader-design.md`.
